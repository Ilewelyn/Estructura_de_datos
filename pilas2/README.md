\# Ejercicios de pilas



Ejercicios pares de la unidad II (pilas) resueltos en Java. 2,4,6,8,10,12.



Todos los archivos están en la carpeta "src". Para compilar y ejecutar cada ejercicio, entra a "src" y usa:



```

javac Ejercicio2.java

java Ejercicio2

```



\---



\## Ejercicio 2



Revisa si un texto cumple con las reglas de parentesis y letras permitidas. Muestra "1" si todo está bien o "0" si hay algun fallo



Ejemplo: "bbba(ac)((a)b)b" -> "1"

\## Ejercicio 4



Calcula cuantos cambios se necesitan para corregir los símbolos en un texto, o indica si es imposible arreglarlos



\- "\[)" -> "1"

\- "{{" -> "imposible"

\- Cadena que ya tiene sentido -> "0"



!\[Ejercicio 4](capturas/Ejercicio4.png)

\## Ejercicio 6



Toma una lista con los nombres de las personas en el orden en que van llegando y los muestra al revés, empezando por el último



Ejemplo: "PABLO, VANESSA, MARIANA, DANIELA, IVAN" -> "IVAN, DANIELA, MARIANA, VANESSA, PABLO"



!\[Ejercicio 6](capturas/Ejercicio6.png)



\---



\## Ejercicio 8



Procesa una lista de números decidiendo si guarda un valor o si borra varios elementos según la cantidad acumulada

Muestra al final cuántos quedaron.



Ejemplo: imprime "2" y luego "2 8"



!\[Ejercicio 8](capturas/Ejercicio8.png)



\---



\## Ejercicio 10



Busca la secuencia de paréntesis más larga que esté bien armada dentro de un texto y cuenta cuántas veces se repite



\- ")((())))(()())" -> "6 2"

\- ")((" -> "0 1"



!\[Ejercicio 10](capturas/Ejercicio10.png)

\## Ejercicio 12



Sigue una lista de instrucciones: agrega números, suma los últimos dos o muestra el valor que está hasta arriba



Ejemplo: imprime "3","4" y "7"
